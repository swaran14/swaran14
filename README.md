## 🚀 Projects

### 🌐 AI-Driven Enterprise Network Monitoring & Automation Platform

**Stack:** `Python` · `Flask` · `scikit-learn` · `SNMP/telemetry` · `SQL`

Final-year major project: monitors live network telemetry and applies ML models to flag anomalies before they become outages, with automated remediation hooks. Chosen deliberately to bridge the networking career path with applied AI.

| Feature | What it does |
|---|---|
| 📡 Live Telemetry Ingestion | Pulls device/interface metrics in real time |
| 🤖 Anomaly Detection | ML model flags abnormal traffic/latency patterns |
| ⚙️ Automated Response | Triggers alerts/remediation on detected anomalies |
| 📊 Dashboard | Visual view of network health across devices |

### 🔍 Cyber Forensic Evidence Analyzer

**Stack:** `Python` · `hashlib` · `Tkinter`

Digital investigation tool that collects, verifies, and analyzes electronic evidence — hash generation, tamper detection, and metadata extraction for chain-of-custody integrity.

| Feature | What it does |
|---|---|
| 🔐 Hash Verification | SHA-256 fingerprinting to detect tampering |
| 🕵️ Metadata Extraction | Pulls file/system metadata for investigation |
| 📄 Report Generation | Structured evidence summary output |
